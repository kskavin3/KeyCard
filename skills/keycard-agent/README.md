# KeyCard agent skill

The skill uses `https://key-card-one.vercel.app` for API discovery and the
payment-gated proxy URLs returned by that server.

Install for the current user:

```sh
npx --yes git+https://github.com/kskavin3/KeyCard.git
```

Install only in the current project:

```sh
npx --yes git+https://github.com/kskavin3/KeyCard.git --project
```

Use `--force` to replace an existing installation.
