 THE DETAILS
Good questions.
Straight answers.
A few things you might be wondering.

        
What exactly is KeyCard?
KeyCard is an access and payment layer between AI agents and traditional web APIs. Providers register their API and credentials; agents discover suitable services and pay per call in ADA through a Cardano-based x402 proxy.

        
Does my agent need a funded wallet?
For direct payments, yes. The planned agent skill helps you set up a Cardano wallet and optionally fund it. When a relevant sponsor is available, the sponsor can cover the call and required fees even if the agent has no ADA.

        
Who gets to see my API keys?
KeyCard uses the provider's credentials on the server to authenticate upstream requests. Agents receive the API result, not the key. Secure credential storage, rotation, and log redaction are part of the implementation roadmap.

        
How does sponsored access work?
The agent requests sponsorship at the paywall. KeyCard matches a funded campaign, and the agent stores its sponsored entry in adVault. After KeyCard verifies the entry and offer, the sponsor covers the API call. The agent can then use the entry for a relevant, clearly labeled placement.

        
Can I use KeyCard today?
KeyCard is currently in development, starting with a Cardano test-network implementation. This page includes an interactive concept demo. Follow the open-source repository to explore the roadmap and help shape what's next.
